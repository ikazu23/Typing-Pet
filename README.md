# タイピングペット (TypingPet)

Xなど他のアプリの上にフワッと浮かぶ、丸っこいペットのオーバーレイアプリです。専用キーボードは不要で、普段使っているキーボードのままで大丈夫です。どこかの入力欄に文字を打つたびに、ペットの表情が4種類に切り替わってちょこっと跳ねます。

仕組み：①「他のアプリの上に表示」権限で画面にペットを浮かせ、②アクセシビリティ機能でどこかの入力欄が変化したことだけを検知（内容自体は読み取りません）してペットに知らせています。

## GitHubでビルドする（Android Studio不要）

1. このフォルダの中身をGitHubの新規リポジトリにそのままpushします。
2. **Actions** タブを開くと `Build APK` が自動で走ります（手動で走らせたい場合は `Run workflow`）。
3. 完了したら実行結果ページ下部の **Artifacts** から `typing-pet-debug-apk` をダウンロードし、zipを展開して `app-debug.apk` を取り出します。

## スマホでの使い方

1. `app-debug.apk` をスマホに転送してインストール（初回は「提供元不明のアプリ」許可が必要）。
2. アプリを開き、①「他のアプリの上に表示を許可」→ 設定でON。
3. ②「アクセシビリティ設定を開く」→ 一覧から「タイピングペット」をON（Android標準の警告文が出ますが、機能の説明どおり入力の検知以外は何もしません）。
4. ③「ペットを表示する」をタップ。
5. Xなど好きなアプリを開いて文字を打つと、画面上に浮かんだペットが反応します。指でドラッグして好きな位置に動かせます。

## 中身について（ファイル4つだけ）

- `MainActivity.kt` : 権限設定への導線（画面はコードで組んでいてレイアウトXMLなし）
- `PetView.kt` : ペットのイラストをCanvasで描画（4表情＋バウンス）
- `OverlayService.kt` : ペットを画面上に浮かせて表示し、ドラッグ移動も担当
- `PetAccessibilityService.kt` : 他アプリでの入力を検知してペットに知らせる
