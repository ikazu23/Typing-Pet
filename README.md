# タイピングペット (TypingPet)

キーを打つたびに表情が切り替わる、丸っこいペットが乗った日本語対応キーボード（IME）アプリです。
Xやその他のSNSアプリなど、テキスト入力ができる場所ならどこでも、このキーボードに切り替えるだけでペットが上に表示されます。

## GitHubでビルドする（Android Studio不要）

1. このフォルダの中身をGitHubの新規リポジトリにそのままpushします。
2. GitHubの **Actions** タブを開き、`Build APK` ワークフローが自動実行されるのを待ちます（pushで自動的に走ります。手動で走らせたい場合は `Run workflow` を押してください）。
3. 完了したら、そのワークフロー実行結果のページ下部にある **Artifacts** から `typing-pet-debug-apk` をダウンロードします（zipで落ちてくるので展開してapp-debug.apkを取り出します）。

## スマホへのインストール

1. ダウンロードした `app-debug.apk` をスマホに転送し、タップしてインストールします（初回は「提供元不明のアプリ」の許可が必要です）。
2. 設定アプリ → システム → 言語と入力 → 画面上のキーボード → キーボードを管理 で「タイピングペット」をオンにします。
3. Xなど好きなアプリの入力欄をタップし、キーボード切り替えアイコン（🌐など）から「タイピングペット」を選びます。

## 中身について

- `PetView.kt` : ペットのイラストをCanvasで描画するカスタムView。打鍵ごとに4種類の表情（ふつう/びっくり/にっこり/ウインク）を切り替え、軽くバウンスします。
- `TypingPetIME.kt` : キーボード本体（InputMethodService）。キーが押されるたびに `PetView.react()` を呼びます。
- `res/xml/qwerty.xml` : 簡易的な英字QWERTYキーボードのレイアウト定義です。
