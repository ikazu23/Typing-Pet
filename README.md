# タイピングペット (TypingPet)

Xなど他のアプリの上にフワッと浮かぶ、丸っこいペットのオーバーレイアプリです。専用キーボードは不要で、普段使っているキーボードのままで大丈夫です。どこかの入力欄に文字を打つたびに、ペットの表情(または追加した自分のイラスト)が切り替わってちょこっと跳ねます。「！」「？」を専用イラストに割り当てることもできます。

仕組み：①「他のアプリの上に表示」権限で画面にペットを浮かせ、②アクセシビリティ機能でどこかの入力欄が変化したことを検知してペットに知らせています。基本的には変化があったことだけを見ますが、「！」「？」専用イラストを設定している場合のみ、直前に追加された文字にこの記号が含まれるかをその場で判定します（保存・送信は一切しません）。

## 設定できること

- **サイズ**：小 / 中 / 大 / 特大
- **揺れの強さ**：なし(画像だけ切り替え) 〜 3段階
- **常に最前面に固定**：ONで他アプリを開くたびに自動表示、OFFで手動表示のみ
- **位置ロック**：ONでタップが下のアプリに素通りし、ドラッグ移動も不可に
- **位置の初期化**
- **内蔵プリセット4色**から選択
- **自分のイラストを追加**：最大4枚まで登録可能。1枚なら常時表示、複数なら打鍵ごとに順番切り替え（全部削除すると内蔵プリセットに自動で戻ります）
- **「！」「？」専用イラスト(任意)**：設定すると、それぞれの記号を入力した瞬間だけそのイラストに切り替わります。未設定ならこれまで通りの反応のままです。

## GitHubでビルドする（Android Studio不要）

1. このフォルダの中身をGitHubの新規リポジトリにそのままpushします（`.github`フォルダごと。隠しフォルダなので、Finder/エクスプローラーの表示設定に注意するか、GitHub上で直接ファイルを作成してください）。
2. **Actions** タブを開くと `Build APK` が自動で走ります（手動で走らせたい場合は `Run workflow`）。
3. 完了したら実行結果ページ下部の **Artifacts** から `typing-pet-debug-apk` をダウンロードし、zipを展開して `app-debug.apk` を取り出します。

## スマホでの使い方

1. `app-debug.apk` をスマホに転送してインストール（初回は「提供元不明のアプリ」許可が必要）。
2. アプリを開き、①「他のアプリの上に表示を許可」→ 設定でON。
3. ②「アクセシビリティ設定を開く」→ 一覧から「タイピングペット」をON（Android標準の警告文が出ますが、上記の「！」「？」判定以外は何もしません）。
4. ③「ペットを表示する」をタップ。
5. 「プリセット」タブで好きな色を選ぶか、「イラスト」タブで自分の画像を追加。「！」「？」専用イラストもここから設定できます。
6. Xなど好きなアプリで文字を打つと、ペットが反応します。ドラッグで位置も変えられます。

## 中身について

- `Prefs.kt` : すべての設定の保存・読み込み（！／？専用イラストのURIも含む）
- `MainActivity.kt` : 設定画面（権限ボタン＋基本設定/プリセット/イラストの3タブ、すべてコードで組み立て）
- `PetView.kt` : ペットのイラストをCanvasで描画（内蔵4色×4表情 / カスタム画像 / ！？専用画像）
- `OverlayService.kt` : ペットを画面上に浮かせて表示。設定変更をリアルタイム反映
- `PetAccessibilityService.kt` : 他アプリでの入力を検知してペットに知らせる。「！」「？」専用イラストが設定されている場合のみ、直前に追加された文字にその記号が含まれるかをその場で判定する
